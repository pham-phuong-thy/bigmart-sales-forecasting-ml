# 🛒 BigMart Sales Prediction using Machine Learning

## 📌 Project Overview
This project builds and compares multiple machine learning models to predict product sales for BigMart retail stores. The objective is to identify the best-performing model and uncover the key factors influencing sales to support business decision-making.

## 🎯 Objectives
- Predict product sales using store and product attributes.
- Compare the performance of multiple regression models.
- Analyze feature importance to identify key sales drivers.

## 📊 Dataset
- **Source:** BigMart Sales Prediction Dataset (Kaggle)
- **Observations:** 8,523
- **Products:** 1,559
- **Stores:** 10
- **Target Variable:** `Item_Outlet_Sales`

## ⚙️ Project Workflow
1. Exploratory Data Analysis (EDA)
2. Data Cleaning & Preprocessing
3. Feature Engineering
4. One-Hot Encoding
5. Model Training & Hyperparameter Tuning
6. Model Evaluation
7. Feature Importance Analysis
8. Business Insights

## 🤖 Models
- Linear Regression
- Lasso Regression
- Random Forest Regressor
- XGBoost Regressor
